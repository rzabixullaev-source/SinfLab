# Qaror 0001: boshlang‘ich texnologiya

Sana: 2026-10-16
Holat: qabul qilindi, provayderlar keyin tanlanadi.

## Tanlov

- Web: React + TypeScript + Vite.
- API: Node.js + Express + TypeScript.
- Ma’lumotlar: PostgreSQL.
- Fayllar: S3 mos object storage interfeysi.
- Jonli media: provayder adapteri; keyin boshqariladigan video xizmati yoki o‘z serverimiz tanlanadi.
- AI: provayder adapteri; model nomi domen va bazaga bog‘lanmaydi.
- Laboratoriya: LabKit interfeysi orqali fan modullari; kiber mashqlar alohida sandbox.

## Sabab

Jamoaning React/Express tajribasi bilan tez boshlash mumkin. Xona a’zoligi, dars, vazifa, test va urinishlar bir-biriga aniq bog‘langan; PostgreSQL shu aloqalar, takrorlanmaslik va huquq qoidalarini saqlash uchun mos. Provayder adapterlari dars oqimini tanlangan video yoki AI xizmatidan ajratadi.

## Natija

Dastlab bitta to‘liq dars oqimi quriladi. Kattaroq jonli sinflar uchun video infratuzilmasi alohida tanlanadi; mavjud kichik peer-to-peer xonani ko‘p o‘quvchiga mo‘ljallangan tayyor yechim deb qabul qilmaymiz.
