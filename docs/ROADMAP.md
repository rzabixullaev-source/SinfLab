# Ish ketma-ketligi

## Backend — bajarilgan

1. API poydevori, konfiguratsiya, Atlas driver va indekslar.
2. Ro‘yxatdan o‘tish, kirish, JWT, foydalanuvchi.
3. Xona, rollar, taklif va a’zolik.
4. Dars, chat, papka, material yuklash/yuklab olish.
5. Vazifa, topshirish tarixi, feedback, quiz va baholash.
6. Tashqi video havolasi bilan jonli sessiya/davomat; Ohm qonuni laboratoriyasi.
7. O‘quvchining qoldirilgan dars, vazifa va takrorlash ro‘yxati.

Har kichik qismdan keyin butun API test to‘plami bajarildi. Oxirgi natija PROJECT_STATE.md da.

## Backend — keyingi ish

1. Haqiqiy MongoDB Atlas URI bilan smoke/integratsiya sinovi, GridFS va transactionlarini tekshirish.
2. Video provayder API orqali xona yaratish va server tasdiqlaydigan davomat.
3. Materialni sahifa bo‘yicha ajratish, AI savol qoralamasi, ustoz tasdiqlash oqimi.
4. O‘qituvchi overview, bildirishnoma, audit va chuqurroq xavfsizlik sinovlari.
5. Kiberxavfsizlik laboratoriyasi uchun alohida sandbox servisi.

## Frontend — keyingi asosiy bosqich

ReactJS/Vite ilovasida ustoz va o‘quvchi uchun login, xona, dars, chat, material, vazifa, quiz, live, lab va progress ekranlari. Dastlab yuqoridagi ishlaydigan API oqimini ulash, so‘ng dizayn va UX ni yaxshilash.

## Hackathon demo

Ustoz xona ochadi → o‘quvchi taklif bilan kiradi → dars/material → jonli sessiya/davomat → vazifa, quiz va Ohm lab → o‘quvchi progress va ustoz natijalarni ko‘radi.
