# LabKit shartnomasi

Har bir fan moduli bir xil hayot sikliga ega:

1. Ustoz lab template tanlaydi va parametrlarini belgilaydi.
2. API konfiguratsiyani modul sxemasi bilan tekshiradi.
3. O‘quvchi shaxsiy run boshlaydi.
4. Modul vaqt bo‘yicha amallar va natijani qaytaradi.
5. O‘quvchi taxmin, kuzatuv va xulosani topshiradi.
6. Ustoz urinish tarixini va dalilni ko‘rib fikr bildiradi.

Kelajakdagi modul interfeysi: code, kind, version, configuration schema, validateConfiguration, startRun, submitRun, summarizeForTeacher. Fizika/kimyo/matematika modullari brauzerda simulyatsiya bo‘lishi mumkin. Cyber moduli alohida serverda ishga tushadi, vaqt va resurs cheklovi bilan to‘xtatiladi.

Birinchi ishga tushadigan modul tanlangach shu papkaga uning kodi va sinovlari qo‘shiladi.
